# ASCII-обои

> 🎈 Фан-проект, сделан для развлечения.

Генератор обоев в стиле ASCII-арт: картинка, GIF или видео превращаются в узор из символов (`. : - = + * # @`). Работает прямо в браузере, без установки и без сервера. Один файл — `index.html`.

## Возможности

- **Вход:** картинки (PNG, JPG, WebP), анимированные GIF, видео (MP4, WebM). Файл можно выбрать, перетащить в окно или вставить через Ctrl+V.
- **Удаление фона (по желанию):**
  - *по цвету* — быстро и без интернета, для однотонного фона;
  - *нейросетью* — для сложного фона, модель скачивается при первом запуске (~40 МБ).
- **Символы:** 7 готовых наборов (классика, точки, блоки, матрица, катакана, звёзды…) или свой набор; 6 шрифтов; яркость, контраст, порог, инверсия.
- **Цвета:** один цвет, градиент, цвета исходника, радуга; цвет фона; свечение.
- **Готовые стили:** Классика, Матрица, Неон, Терминал, Закат, Лёд, Радуга, Кровь, Цвета фото.
- **Эффекты анимации:** мерцание, цифровой дождь, печать, сборка из шума, глитч, пульсация. Все эффекты зацикливаются без рывка.
- **Подпись** текстом сверху, снизу или по центру.
- **Форматы:** обои на телефон 1080×1920, на ПК 1920×1080, квадрат, как у исходника.
- **Экспорт:** PNG, GIF (бесшовный цикл; у GIF и видео сохраняются кадры и скорость оригинала), видео WebM.

## Как запустить

Откройте `index.html` в браузере (двойной клик). Лучше всего работает в Chrome, Edge или Яндекс.Браузере.

### Онлайн через GitHub Pages

1. Загрузите `index.html` в репозиторий.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Как это работает

1. Кадр уменьшается до сетки, например 110 × 115 клеток: одна клетка — один символ.
2. Для каждой клетки считается яркость от 0 до 1.
3. Яркость выбирает символ из набора: тёмное — пробел, светлое — самый «плотный» символ.
4. Символы рисуются на холсте, поверх добавляются свечение и эффекты.

GIF собирается своим кодировщиком прямо в браузере (LZW-сжатие), а входные GIF разбираются своим декодером, поэтому без сети работает всё, кроме удаления фона нейросетью и сторонних шрифтов.
